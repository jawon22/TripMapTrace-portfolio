# 기획 (PLANNING)

앞으로 할 기능, 우선순위, 요구사항을 정리한다. 구현 세부 계획은 `.claude/plans/`, 완료 이력은 `docs/PROJECT_CONTEXT.md`에 있다.

## 프로젝트 목적
여행 중 촬영한 사진/영상을 **시간 + 위치 + 지도** 기반으로 시각화하는 공유형 기록 앱. 단순 갤러리가 아닌 "여행 경로 시각화 앱".

## 다음 작업 후보 (우선순위 순)
1. App Links 실기기 검증 — APK 재빌드 + 재설치 후 카톡 링크 클릭 테스트 (진행 중)
2. A-1 앱 브랜딩(이름/아이콘) — 기능상 유일하게 남은 항목, 출시 직전 진행
3. (공개 배포 시) 백엔드 HTTPS + 리프레시 토큰 + Play Store 등록

## 별도 조건이 필요한 항목
| 항목 | 조건 |
|------|------|
| iOS Info.plist ATS 예외 | Mac 필요 |
| HTTPS (Cloudflare Tunnel) | 도메인 구매 |
| FCM 알림 Group 2~3 테스트 | 기기 2대 필요 |
| Play Store / App Store 등록 | HTTPS + 심사 |
